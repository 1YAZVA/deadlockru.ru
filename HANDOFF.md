# HANDOFF — фан-сайт DeadlockRU (deadlockru.ru)

## Что это
Глобальный фан-портал Deadlock ( Valve, appid 1422450 ) в стиле тёмного игрового сайта с золотым акцентом.
Одностраничное приложение: 11 разделов на хеш-навигации `#home #news #heroes #meta #items #leaderboard #esports #guides #tools #commands #account`.

## Стек
- **Next.js 16 (App Router) + React 19 + TypeScript 5** (dev-сервер на порту 3000)
- **Tailwind CSS 4** (через @tailwindcss/postcss), lucide-react (иконки), recharts (графики)
- **Prisma 6 + SQLite** — база уже наполнена синками: `db/custom.db` (путь в `.env`, DATABASE_URL=file:...)
- Пакетный менеджер — bun (`bun.lock`), но работает и npm: `npm install`
- Прод-сборка: standalone (`npm run build` → `bun .next/standalone/server.js`), в корне есть Caddyfile

## Запуск
```bash
npm install            # или bun install
npx prisma generate
npm run dev            # → http://localhost:3000
```
База готова к работе сразу — данные героев/предметов/патчей/лидербордов/киберспорта уже в db/custom.db.

## Структура
- `src/app/page.tsx` — хеш-навигация вкладок + History API (кнопка «Назад» работает: вкладки через pushState+hashchange, карточка героя через history.state.dlHero)
- `src/app/globals.css` — вся дизайн-система: золото `--accent:#C8A96A`, `--panel/--panel2/--line/--muted2/--ok/--danger`, классы `card-dl`, `container-dl`, `SectionHeader`, стили рулетки (`.rl-*`), квиза (`.qz-*`), рангов, новостей
- `src/components/site/` — секции вкладок + `roulette.tsx` (рулетка героев с рандом-билдом, вкладом, звуком, конфетти) + 6 инструментов (`tool-compare/builder/patch-impact/live/quiz/sync`)
- `src/app/api/` — роуты: `heroes, hero/[id], items, meta, leaderboard, live, patches, esports, player, search, state, sync, quiz, img` (img — прокси картинок с кэшем `.img-cache`)
- `src/lib/site.ts` — типы, форматтеры, `viaImgProxy`, `apiGet`, `sanitizeHtml`, RU-словари рангов
- `prisma/schema.prisma` — модели (Hero, Item, HeroStat, HeroExtra, Patch, Leaderboard, Esports...). Русская локализация способностей лежит в таблице Item (type="ability", поля nameRu/descriptionRu)
- `public/commands` — самохостные HQ-иконки легендарок (200×200), `public/fonts` — шрифты (все бесплатные, SIL OFL 1.1 — лицензия приложена: `public/fonts/FONTS-LICENSE.txt`)
- `scripts/verify-*.js` — Playwright-проверки фич (звук рулетки, назад, видеофон, квиз, юр-маркировка) — готовые примеры тестов

## Данные и синхронизация
- Источники: deadlock-api.com (герои, винрейты, лидерборды 5 регионов, активные матчи), Steam Web API (онлайн, RSS новостей и патчей), Liquipedia/collegedeadlock (киберспорт)
- Синк вручную: вкладка **Инструменты → Центр автоматизации** (кнопки «Запустить сейчас», журналы, расписания)
- Данные обновляются автоматически по расписанию синков (meta раз в 2 ч, лидерборд раз в 30 мин, новости раз в час) — механизм в `src/app/api/sync` и компоненте ToolSync

## Грабли (важно!)
1. **dev-сервер кэширует CSS** после правок globals.css — перезапускать: `pkill -f "next dev"; pkill -f "next-server"; (nohup ./node_modules/.bin/next dev -p 3000 > dev.log 2>&1 &)`
2. `npx tsc --noEmit` шумит СТАРЫМИ ошибками (BigInt-литералы в `src/lib/buildroll.ts`, `src/app/api/player/route.ts`) — это не ломает билд и не относится к новым правкам
3. `.img-cache/` — регенерируемый кэш прокси-картинок, можно удалять
4. `.env` — только локальный путь к SQLite, секретов нет
5. В HISTORY-паке git не включён в архив (41 МБ снапшотов БД); лог работы ниже
