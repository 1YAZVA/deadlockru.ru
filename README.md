# DEADLOCK.FAN — фан-сайт Deadlock (Valve)

Готовый статический сайт: без сборки, без React, только HTML/CJS + три JSON-файла.
Хостится бесплатно на **GitHub Pages**, редактируется прямо на сайте через админку (коммиты через GitHub API).

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | одна страница-SPA: Главная / Новости / Герои / Билды / DPS-калькулятор / Админка |
| `css/style.css` | тёмная тема в духе игры |
| `js/app.js` | роутер, загрузка JSON, онлайн-счётчик Steam + RSS новостей Valve |
| `js/dps.js` | DPS-калькулятор (урон, темп, бонусы предметов, крит) |
| `js/admin.js` | админка: логин по репозиторию + GitHub-токену, правки карточек героев, билдов, патчей |
| `data/heroes.json` | карточки героев (имя, роль, аватар, описание, статы) |
| `data/builds.json` | билды (предметы через запятую, описание, метки) |
| `data/patchnotes.json` | ваши заметки о патчах |
| `data/*.json` | **именно эти файлы редактирует админка** — руками их править не обязательно |

## Деплой на GitHub Pages (5 минут)

1. Репозиторий сайта: `deadlockru.ru` (пока приватный — публикуем по готовности).
2. Загрузите сюда **содержимое** этой папки (Add file → Upload files; `index.html` должен лежать в корне репозитория!).
3. Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → Save.
4. Через 1–3 мин сайт будет на `https://ваш-ник.github.io/deadlockru.ru/` (или сразу на домене deadlockru.ru).

## Админка (правки прямо на сайте)

1. GitHub → аватар в правом верхнем углу → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**:
   - Repository access: **Only select repositories** → выберите репозиторий сайта;
   - Permissions → Repository → **Contents: Read and write**;
   - срок — поставьте разумный (например, 90 дней).
2. **Секретный вход.** Кнопки в навигации нет. Режим правки открывается только по адресу
   `ваш-сайт/#panel-xk7m2q` (ключ задаётся константой `SECRET_HASH` в `js/admin.js` — **смените его на свой** перед публикацией).
3. После личного входа сайт выглядит как у обычного посетителя, но включается **режим правки**:
   - внизу справа — зелёный **«+»** (добавить новость / героя / сборку);
   - в углу каждой карточки — маленький бейдж **«✎»** (открыть правки; удаление — внутри).
   - справа внизу — тулбар: состояние черновика, **💾 Сохранить** (коммиты в GitHub), **✕ Выйти**.
4. Нажмите **💾 Сохранить** — правки уйдут коммитами. GitHub Pages перевыпустит сайт через 1–3 мин.

Охрана доступа в статическом сайте двухслойная: (1) секретный URL-ключ + (2) GitHub-токен, который лежит только в вашем браузере. Токен выдаёт Contents:Write только на этот репозиторий — на сайт он никак не влияет без вашего ведома.

⚠️ Токен хранится **только в вашем браузере** (localStorage) и отправляется только на `api.github.com`.
Но: любой, кто откроет админку на этом же ПК, сможет достать его из localStorage — поэтому не заходите в админку с чужих машин (или чистите после работы: кнопка «Выйти» удаляет токен).

## Локальный просмотр

Fetch не работает с `file://`, поэтому для локальной отладки поднимите сервер, например:

```
python -m http.server 8000   # и откройте http://localhost:8000
```

или используйте Live Server в VS Code.

## Где брать данные

- **Онлайн**: главный источник — `data/live.json`, каждые 5 мин обновляется GitHub Actions (workflow `.github/workflows/live.yml`): берёт живой счётчик с официальной страницы Steam Store (`nConcurrentInGame`) и пик за 24 ч из Steam Charts. В браузере как запас — Steam CCU API / SteamSpy.
- **Официальные новости**: RSS `store.steampowered.com/feeds/news/app/1422450/` — блок в разделе «Новости».
- **Статы героев / предметов**: стартовые значения в `data/*.json` — **приблизительные заглушки**. Проверяйте и правьте их в админке по актуальным патчам Deadlock (или возьмите точные данные из deadlock-api.com / datamining).
- **Билды**: предметы и порядок — примеры-заготовки, сверьте названия с актуальным деревом предметов.
